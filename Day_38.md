💡 Key Learning

My biggest learning from this project was that analytics become valuable only when they turn raw data into actionable feedback.

While building the dashboard, I learned how real-time typing data such as keystrokes, correct and incorrect characters, elapsed time, typing rhythm, and mistakes can be transformed into meaningful insights like WPM trends, consistency scores, error heatmaps, streaks, and personalized suggestions.

I also learned that building a polished interactive application is not only about adding more features. The real challenge is making UI, calculations, state management, visual feedback, and user experience work together smoothly.
